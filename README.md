# Fostering Human Factors

The personal portfolio of Taylor Foster, M.S. in Human Systems Engineering from Arizona State University.

**Website:** [fosteringhumanfactors.tech](https://fosteringhumanfactors.tech)

## About

Fostering Human Factors showcases selected research, engineering, and human-centered design work exploring how people interact with complex technical systems.

The portfolio is organized around five themes:

- Designing for Safety
- Trust as Infrastructure
- Designing for Ventures
- Knowledge as Infrastructure
- Designing for Resilience

Selected case studies examine the research questions, methods, design decisions, individual contributions, and limitations behind my work.

## Repository

This repository contains the source files for my portfolio website, published through GitHub Pages.

The website documents academic research, professional experience, collaborative projects, and independent work.
